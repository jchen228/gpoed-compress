rate_distortion_comparison.py — Step-by-Step Algorithm Guide

This document explains what every algorithm in the script does, in the order executed. Coloured highlights show variables and toggles that are shared across methods.

abs_bound — residual error tolerance (same sweep for all methods)
k — number of sensors / modes / basis vectors
DS — spatial downsampling factor (10 → 50×50/level)
NUM_BINS — quantization bins (65536, matching SZ2)
LEVEL — z-slice used for PSNR/SSIM evaluation
CR / CR_no_model — compression ratio outputs
model_b — losslessly stored model bytes
quantize / pack_encode — shared SZ-style coder

0 — Shared Infrastructure

0.1 Quantizer (quantize / dequantize)

Every method (except SZ2/ZFP which use libpressio internally) runs residuals through the same SZ-style quantizer. This ensures a fair apples-to-apples comparison.

① Compute bin_width = 2 × abs_bound / NUM_BINS.
② For each residual value: bin_index = round(value / bin_width). Values whose |bin_index| ≥ NUM_BINS/2 are "outliers" — stored as raw float32 (same as SZ2's unpredictable-point storage).
③ Non-outlier bins stored as int16. Outlier positions stored as int32.
bin_width = 2 × abs_bound / 65536

0.2 Entropy coder (pack_encode)

Mirrors SZ2's Huffman + Zstd pipeline without actually encoding (for speed).

① Compute symbol frequency distribution of bin indices.
② Estimate compressed size via Shannon entropy: size = ⌈H × n / 8⌉ + codebook, where H is entropy in bits/symbol.
③ Compress outlier positions with Zstd; outlier values stored raw.
④ Return a dummy bytes object of exactly this estimated length — used only for CR computation.

0.3 Model compression helpers

All model components are compressed losslessly before counting bytes:

FunctionDtypeUsed for
compress_f16(a)float16 + ZstdBasis matrices (Phi, K_Xs)
compress_f32(a)float32 + ZstdMean, std, Cholesky factors
compress_i32(a)int32 + ZstdSensor location indices

0.4 Metrics

All methods evaluate quality on the LEVEL=50 z-slice of the downsampled reconstruction.

PSNR = 20 × log₁₀( (max−min) / RMSE )
SSIM = structural_similarity(orig, recon, data_range=max−min)

0.5 Compression ratio

CR = (n_3D_ds × 4 bytes) / total_compressed_bytes
CR_no_model = (n_3D_ds × 4) / (sv_bytes + resid_bytes) ← model storage treated as free

n_3D_ds = n_levels × (500/DS) × (500/DS) — the actual bytes being compressed. MultiGP uses d × n_3D_ds since it jointly compresses 2 fields.

1 — SZ2 (baseline)

Mode: absolute error bound. Library: libpressio. Input: full 3D downsampled volume.

① Downsample: data_ds = data[:, ::DS, ::DS] → shape (100, 50, 50). np.ascontiguousarray required for libpressio.
② Compress: call libpressio with {"pressio:abs": abs_bound}. SZ2 internally runs: Lorenzo predictor → quantize → Huffman → Zstd.
③ Decompress: libpressio decode → reconstructed array.
④ Metrics: PSNR/SSIM on data_ds[LEVEL] vs recon[LEVEL].
⑤ CR: read from comp.get_metrics()["size:compression_ratio"] — this is libpressio's own measurement.

Sweep: ABS_BOUNDS = logspace(−4, −0.5, 8). One row per abs_bound.

2 — ZFP (baseline)

Mode: fixed-accuracy (absolute error). Library: libpressio. Input: same downsampled volume as SZ2.

① Same downsample step as SZ2.
② Compress: call libpressio with {"zfp:accuracy": abs_bound}. ZFP internally uses a wavelet-like block transform on 4×4×4 blocks.
③–⑤ Decompress, metrics, and CR identical to SZ2.

Sweep: ZFP_ABS_BOUNDS = logspace(−4, −0.5, 8) (same range as SZ2). abs_bound stored in CSV for both methods.

Why fixed-accuracy? The reference paper (Error-Controlled Lossy Compression… Fig. 6) used absolute error bound mode for both SZ and ZFP. Fixed-rate ZFP gives worse RD curves on this data.

3 — T-DEIM (Tensor DEIM)

Outer loop: k (basis vectors). Inner loop: abs_bound (residual quantization).

3.1 Offline (once per run)

① Downsample: data_ds = data[:, ::DS, ::DS] → (n_L, 50, 50).
② Subtract mean: F = (data_ds − mean_ds).reshape(n_L, n_2D) — snapshot matrix shape (100, 2500).
③ SVD: Phi, svs = tdeim.build_3d_basis(F, k_max). Phi is shape (n_3D_ds, k_max) — the global 3D POD basis. This is the key difference from DEIM-2D: modes span all levels simultaneously.

3.2 Per-k (offline, model building)

① Truncate: Phi_k = Phi[:, :k] shape (n_3D_ds, k).
② Q-DEIM sensor placement: QR with column pivoting on Phi_k.T → pivot indices p[:k] into the flat 3D array. Sensors are distributed across levels and spatial locations.
③ Model bytes: model_b = |compress_f16(Phi_k)| + |compress_i32(sensors)| + |compress_f32(mean_ds)|.
④ Read sensor values: y_s = data_flat[sensors] — exact float32, centred. Encode as float16 + Zstd → sv_enc.
⑤ Reconstruct (once): solve Phi_k[sensors, :] · c = y_s → c → recon = Phi_k · c + mean. Residual = data_ds − recon.

3.3 Per-abs_bound (online, compression)

① Quantize residuals: quantize(resid, abs_bound, NUM_BINS).
② Entropy-encode: pack_encode(bins, outlier_pos, outlier_vals) → resid_enc.
③ CR = (n_3D_ds × 4) / (model_b + |sv_enc| + |resid_enc|).
④ Dequantize, reconstruct final field, compute PSNR/SSIM on LEVEL slice.

4 — MultiGP (d=2, CLOUDf + QVAPORf)

Outer loop: k. Inner loop: abs_bound. Jointly compresses two fields using a Linear Model of Coregionalization (LMC/ICM) GP.

4.1 Offline setup

① Downsample both fields: data_ds0, data_ds1 → each (100, 50, 50). Stack into data_nd shape (100, 2500, 2).
② Train split: randomly select 70% of levels as training data. Compute per-location mean and std across training levels, per field.
③ Fit hyperparameters (lengthscale ls, variance var, cross-field covariance matrix B) via maximum likelihood on normalized training data. Uses Matérn-5/2 kernel evaluated on a coarse grid (HP_DS=5) for speed.
④ Max-k sensor placement (GKS/RPCholesky): greedy kernel column selection on the full 2500-point grid to find the most informative locations. Precomputed once.

4.2 Per-k

① Take first k sensor locations s_k. Assemble block kernel matrix K_sub = kron(B, K_ss_k) + σ²I shape (d·k × d·k).
② Cholesky factor L_kd of K_sub. Compute cross-covariance K_Xs shape (n_2D, k).
③ Model bytes: compress_f16(K_Xs) + compress_f32(L_kd) + compress_f32(train_mean) + compress_f32(train_std) + compress_f32(B) + compress_f16(hyperparams) + compress_i32(sensor_indices).
④ Read sensor values for both fields: all_sv_orig shape (n_L, k, 2). Encode as float16 flat → sv_enc.

4.3 Prediction (per-k, once)

① For each level: y_norm = [normalize(sensors_field0), normalize(sensors_field1)] shape (2k,).
② Solve: alpha = L_kd \ y_norm (Cholesky back-solve).
③ GP posterior mean for field i: mu_i = Σ_j B[i,j] × K_Xs × alpha[j·k:(j+1)·k]. Denormalize → reconstruction.
④ Residual for both fields: resid = (data_nd − recon_nd).ravel().

4.4 Per-abs_bound

① Quantize joint sensor values and residuals with abs_bound.
② CR = (2 × n_3D_ds × 4) / total_bytes — numerator is ×2 because two fields jointly compressed.
③ Metrics on LEVEL slice of field 0 (CLOUDf) and field 1 (QVAPORf), stored separately in CSV.

5 — DEIM-2D (per-level 2D SVD)

Key difference from T-DEIM: SVD computed on the 2D spatial snapshot matrix (n_L × n_2D) → modes are purely spatial; sensors observe within a single 2D slice. Model is 100× smaller than T-DEIM.

5.1 Offline

① Downsample: data_ds → (100, 50, 50).
② 2D snapshot SVD: F = (data_ds − mean).reshape(n_L, n_2D). SVD of F → right singular vectors V shape (n_2D, n_2D). These are the 2D spatial modes.

5.2 Per-k

① Phi_k = V[:, :k] — top-k 2D spatial modes, shape (n_2D, k).
② Q-DEIM sensor placement: QR with pivoting on Phi_k.T → k sensor locations within the 2D spatial grid. Same k sensors used for every level.
③ Model bytes: compress_f16(Phi_k) + compress_i32(sensors) + compress_f32(mean).
④ Read sensor values (exact, no quantization): all_sv[lvl] = data_ds[lvl].ravel()[sensors] for each level → shape (n_L, k). Stored as float16 → sv_enc_exact.
Sensors stored exact (float16) rather than quantized, because DEIM interpolates exactly at sensor locations — the residual at sensors is exactly zero. Quantizing sensors would inject artificial error into the solve.
⑤ Reconstruct (once per k): For each level, solve A · c = sv[lvl] where A = Phi_k[sensors, :]. Then recon[lvl] = Phi_k · c + mean.
⑥ resid = (data_ds − recon_ds).ravel().

5.3 Per-abs_bound

① Quantize residuals with abs_bound and NUM_BINS=65536.
② CR and CR_no_model computed same as T-DEIM. Metrics on LEVEL slice.

6 — Kriging-2D (per-level GP, d=1)

Key difference from DEIM-2D: uses a Gaussian Process (Matérn-3/2 kernel) instead of linear modes. Sensor placement via RPCholesky / GKS. No basis matrix to store — model is the kernel hyperparameters + Cholesky of the sensor kernel matrix.

6.1 Offline

① Downsample → (100, 50, 50). Grid coords normalized to [0,1]².
② Train split: 70% of levels used to fit hyperparameters.
③ Fit hyperparameters (ls, var) via joint MLE on a coarse HP_DS=5 subgrid (10×10 = 100 points). Uses 3 random restarts for robustness.
④ Max-k sensor placement (GKS): greedy kernel column selection on the full 2500-point grid. First k columns give the most informative sensor locations.

6.2 Per-k

① Take first k sensors s_k. Assemble K_ss_k (k×k sensor kernel) + noise diagonal.
② Cholesky: L_k = cholesky(K_ss_k + σ²I). Assemble cross-covariance K_Xs shape (n_2D, k).
③ Model bytes: compress_f16(K_Xs) + compress_f32(L_k) + compress_f32(train_mean) + compress_f32(train_std) + compress_f16(hyperparams) + compress_i32(sensor_indices).
④ Read sensor values (exact): all_sv[lvl] = data_ds[lvl].ravel()[s_k]. Stored as float16 → sv_enc_exact.
⑤ Reconstruct (once per k, hoisted out of abs_bound loop): For each level: normalize sensors → alpha = L_k \ y_norm → mu = B[0,0] × K_Xs × alpha → denormalize → recon_ds[lvl].
⑥ resid = (data_ds − recon_ds).ravel().

6.3 Per-abs_bound

① Quantize residuals with abs_bound.
② CR and CR_no_model identical formula to DEIM-2D. Metrics on LEVEL slice.
